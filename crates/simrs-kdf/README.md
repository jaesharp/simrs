# simrs-kdf

HMAC-SHA-256 and 3GPP key derivation functions.

Provides HMAC-SHA-256 (RFC 2104), the generic 3GPP KDF (TS 33.220
Annex B), 4G EPS-AKA key derivations (TS 33.401 Annex A), EAP-AKA'
key derivation (TS 33.402 / RFC 5448), and 5G NR key derivations
(TS 33.501 Annex A).

`no_std`. No heap allocation.
